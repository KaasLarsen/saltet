**Cosori TurboBlaze (CAF-DC602)** er næste generation single basket: **DC-motor**, **fem blæserhastigheder**, ca. **6 L**. Hurtigere og mere præcis luftstrøm end mange AC-maskiner i samme liter-klasse.

Max Crisp-rival: [Ninja AF180](/anmeldelser/ninja-max-pro-af180). Top+bund: [Dual Blaze](/anmeldelser/cosori-dual-blaze). Dual Cosori: [TwinFry](/anmeldelser/cosori-dual-blaze-twinfry).

## Specifikationer der betyder noget

| | Cosori TurboBlaze |
|---|---|
| Koncept | Single basket, **DC-blæser** |
| Kapacitet | **6 L** |
| Effekt | ca. **1725 W** |
| Blæser | 5 hastigheder |
| Temp | typisk op til ca. 230 °C-klassen |
| Programmer | 9-in-1 / Chef Edition-varianter |

## DC-luft i praksis

**Pommes.** Hurtigere opstart, jævnere brunering i ét lag. [Frosne pomfritter](/opskrifter/airfryer/frosne-pomfritter).

**Grønt / chips.** Lavere blæsertrin kan skåne lette stykker. [Grøntsags-chips](/opskrifter/airfryer/groentsags-chips).

**Ikke Dual Blaze.** Ingen undervarmelegeme. Vend stadig tykke stykker.

## Hverdagstest

**Hverdag:** Hurtig single til par. Se [airfryer for begyndere](/guides/airfryer-for-begyndere).

**Sprødhed:** Tæt på Ninja i mange frost-tests — Max Crisp-preset mangler som Ninja-knap.

**Rengøring:** Én kurv. [Rengøringsguide](/grej/airfryer-rengoering).

## Hvem skal købe TurboBlaze?

**Køb hvis:** Én kurv, vil have moderne blæser-tech, ikke behøver dual.

**Skip hvis:**

- Max Crisp-knap → [AF180](/anmeldelser/ninja-max-pro-af180)
- Top+bund → [Dual Blaze](/anmeldelser/cosori-dual-blaze)
- Kompakt 4,7 L → [Pro LE](/anmeldelser/cosori-pro-le)
- Mini 3,8 L → [Lite](/anmeldelser/cosori-lite)
