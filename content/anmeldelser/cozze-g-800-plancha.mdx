**Cozze G-800** er det gennemtænkte danske bud: gas-plancha med **LED i knapperne** (hvid → rød når pladen er klar), 3 brændere, ~7,5 kW, låg. Samme hus som Cozze-pizzaovnene — tænkt til danske terrasser.

Rivaler: [Blackstone](/anmeldelser/blackstone-2144eu), [Le Marquier Amalia](/anmeldelser/le-marquier-amalia). Guide: [plancha vs. støbejern](/grej/plancha-vs-stobejern).

## Specifikationer der betyder noget

| | Cozze G-800 |
|---|---|
| Type | Gas-plancha + låg |
| Brændere | **3** (~7,5 kW) |
| Flade | ca. **80 × 50 cm** |
| Særligt | **LED** hvid→rød |
| Plade | Støbejern (glat) |

## LED-testen: hvidløgssvampe

Spørgsmålet er ikke «er LED pænt?» — det er «lyver den?». Varm op til rød. Smid [svampe](/opskrifter/plancha/svampe-frikasse-plancha) på. Hvis de damp-koger i stedet for at brune: pladen var ikke klar, eller du overfyldte. LED er hjælper — [tørstegning](/guides/toerstegning-af-svampe) er stadig disciplin.

## Hverdag på terrassen

Zoner til smash og grønt side om side. Fedtopsamler. Låg til opvarmning/regn-pause. Det er midtpris-udekøkken uden fransk merpris.

## Hvem skal købe G-800?

**Køb hvis:** Dansk gas-plancha, LED-klar-signal, plads til 3 brændere.

**Skip hvis:** Smash-kult → Blackstone. Emalje-livstid → Amalia. Kun el → Taurus. Har grill → Napoleon-indsats.
