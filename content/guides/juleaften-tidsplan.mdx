Juleaften er timing, ikke talent. Denne køreplan antager **flæskesteg + and** til 4–6 personer, servering ca. kl. 18.

Menu og valg: [julemenu](/guides/julemenu-sammensaetning). Prep-tjekliste: [dagen før](/guides/julemiddag-prep). Ovn-konflikt: [én ovn, to stege](/guides/en-ovn-to-stege-juleaften). Teknik: [andesteg komplet](/guides/andesteg-komplet-guide), [flæskesteg i airfryer](/guides/flaeskesteg-i-airfryer).

## 21.–22. december

| Opgaver | Detalje |
|---------|---------|
| Optø and | I køleskab — ikke på bordet. Stor and kan bruge 2 døgn. |
| Indkøb | Kød, kål, kartofler, ris, mandler, fløde, sukker, kirsebær, fond |
| [Rødkål](/opskrifter/sylte/klassisk-roedkaal-andefedt) | Smager bedre dagen efter. Alternativ: [hjemmelavet gryde](/opskrifter/gryde/hjemmelavet-roedkaal) |
| [Kirsebærsovs](/opskrifter/gryde/kirsebaersauce) | Kan stå i køl; varm forsigtigt d. 24 |

Salt anden natten før stegning hvis I steger d. 23. Dup knastørt. Score skindet. Se [andesteg-guiden](/guides/andesteg-komplet-guide).

## 23. december

Dagen der fjerner panikken fra d. 24.

| Opgaver | Detalje |
|---------|---------|
| Langtidssteg [and](/opskrifter/ovn/sproedstegt-andesteg-aebler-svesker) | Følg opskrift. Termometer i låret 80–82 °C. |
| Si fond / sky | Afkøl. Fedt af til sovs d. 24 — [andesovs](/opskrifter/dips/andesovs) eller [andesky](/opskrifter/dips/andesky) |
| Afkøl og skær | Kød og skind adskilt i køl. Genopvarmning bliver lettere. |
| [Risengrød](/opskrifter/gryde/klassisk-risengrod) | Aftengrød eller base til [risalamande](/opskrifter/gryde/risalamande-kirsebaersauce). Alternativ: [airfryer](/opskrifter/airfryer/risengrod-airfryer) |
| Smut mandler | Til risalamande. Én hel mandel gemmes. |
| Kog og pil kartofler | Til [brunede kartofler](/opskrifter/gryde/brunede-kartofler). Opbevar i koldt vand i køl. |
| Flæskesteg klar | Rid svær, salt, **åbent i køleskab** natten over — tør overflade = knas. Opskrift: [gammeldags flæskesteg](/opskrifter/ovn/gammeldags-flaeskesteg-sproede-svaer) |

Mere om hvad der må laves i forvejen: [prep-guiden](/guides/julemiddag-prep).

## 24. december — time for time

Servering **ca. kl. 18**. Flyt hele skemaet hvis I spiser tidligere eller senere. Flæskestegens tid følger vægt — tjek opskrift og termometer.

| Tid | Handling |
|-----|----------|
| 10:00–11:00 | Tag flæskesteg ud 30–45 min før ovn (ikke iskold i ovnen). Dup svær. Tjek and, rødkål, fond, kartofler i køl. |
| 12:00 | Risalamande færdiggøres (fløde, mandler, vanilje) — hold kold. Kirsebærsovs klar til opvarmning. |
| 14:00–14:30 | **Flæskesteg i ovn** — følg [ovnopskrift](/opskrifter/ovn/gammeldags-flaeskesteg-sproede-svaer) eller [airfryer](/opskrifter/airfryer/flaeskesteg) hvis den er lille. |
| 16:00–16:30 | Kernetemperatur på flæskestegen (træk ca. 65–68 °C). Hvil under løst folie. **Svær-boost** ved høj varme hvis den mangler knas. |
| 16:45 | Start [flæskestegssovs](/opskrifter/pande/flaeskestegssovs) af dryp + fond. Varm andefond til andesovs i anden gryde. |
| 17:00–17:15 | **And genopvarmes:** kød lavt under låg med fond. Skind i airfryer/ovn 3–6 min til knas — ikke længere. |
| 17:20 | Varm rødkål. Sæt tallerkener og fade klar. |
| 17:30–17:40 | **Brunede kartofler** — [gryde](/opskrifter/gryde/brunede-kartofler), [pande til and](/opskrifter/pande/brunede-kartofler-and) eller [airfryer](/opskrifter/airfryer/brunede-kartofler-airfryer). Ikke tidligere. |
| 17:45 | Montér sovsene (jævn, smag til salt/syre). Skær flæskesteg og and. |
| 18:00 | Server. Risalamande + kirsebær efter. |

Kun én ovn? Læs [én ovn, to stege](/guides/en-ovn-to-stege-juleaften) før I flytter tider.

## Fejl der ødelægger aftenen

- **Brunede kartofler for tidligt** — de bliver bløde. Brun lige før.
- **And genopvarmet for hårdt** — den tørrer. Lav varme + separat skind-boost.
- **Våd flæskesvær i ovnen** — damper i stedet for at boble. Tør natten over.
- **Ingen termometer** — svær og skind lyver. Kernetemperatur bestemmer.
- **Alt i ovnen samtidig uden plan** — damp og forkert temperatur. Se ovn-guiden.

Går det galt alligevel: [SOS juleaften](/fejlfinding/sos-juleaften).
